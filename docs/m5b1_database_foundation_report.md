## H. Test Database Strategy
Tests explicitly override the connection using a `sqlite:///:memory:` URL. Because SQLite lacks native JSONB and UUID, fallback compiler hooks were implemented in the models solely to allow offline schema compilation testing. This guarantees that running `pytest` does not accidentally wipe or modify a developer's local production PostgreSQL instance.
