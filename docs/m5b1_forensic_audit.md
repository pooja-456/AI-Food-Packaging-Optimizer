## 15. Test Isolation Audit
**Status:** PASS WITH LIMITATION.
The test harness configures `sqlite:///:memory:`. Because SQLite doesn't natively support `UUID` or `JSONB`, the models utilize `@compiles` decorators to silently downgrade `JSONB` to `JSON` and `UUID` to `VARCHAR(36)` during compilation tests. While this successfully protects production Postgres instances from test-wipe collateral damage, it prevents the test harness from checking advanced Postgres-specific JSONB query operators (`@>`).
