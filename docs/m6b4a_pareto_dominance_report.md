# M6-B4A: Pareto Dominance Engine Report

**Project**: AI-Based Intelligent Food Packaging Material Recommendation System
**Milestone**: M6-B4A
**Date**: 2026-09-29

## 1. Objective
Implement the fundamental mathematical predicate for Pareto dominance (`dominates(A, B)`) using the four approved deterministic objective vectors generated by M6-B3.

## 2. Mathematical Definition
The implementation evaluates whether Candidate A strictly dominates Candidate B.
Candidate A dominates B if and only if:
1. A is no worse than B in EVERY active objective.
2. A is strictly better than B in AT LEAST ONE active objective.
(Equality in all objectives implies no dominance).

## 3. Objective Directions
Directions explicitly drive the `<` and `>` evaluations:
- `f_thickness` (MINIMIZE): Lower is better.
- `f_moisture_margin` (MAXIMIZE): Higher is better.
- `f_gas_alignment` (MINIMIZE): Lower is better.
- `f_shelf_life_margin` (MAXIMIZE): Higher is better.

## 4. Feasibility Eligibility
Any vector containing an `UNKNOWN` CalculationStatus immediately returns `False` (no dominance can be proven). Since M6-B3 maps `INFEASIBLE` and unknown condition materials to `UNKNOWN` objectives, this completely natively preserves the rule that infeasible packages cannot dominate or enter the Pareto front.

## 5. Interval/Uncertainty Behavior
Strict Dominance with Uncertainty Bounding is used natively. Midpoint collapses are prohibited.
- For `MINIMIZE`: `A` is better than `B` only if `worst_case(A) < best_case(B)` (`value_max(A) < value_min(B)`).
- For `MAXIMIZE`: `A` is better than `B` only if `worst_case(A) > best_case(B)` (`value_min(A) > value_max(B)`).
If intervals overlap, neither candidate strictly dominates the other, ensuring scientifically conservative preservation of uncertainty.
